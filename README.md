# chess

西洋棋練習題目與技巧提升訓練平台 (Chess Training Hub)

一個純前端、免安裝、隨開即練的西洋棋專項技能訓練網頁。

## 🎯 功能特色

1. **戰術謎題挑戰 (Tactics Trainer)**
   - 包含底線悶殺、騎士捉雙 (Fork)、絕對牽制 (Pin)、串擊 (Skewer)、消除防衛者 (Deflection)、閃擊打擊、棄后絕殺等經典題型。
   - 即時步法判斷、提示系統與戰術解說。

2. **30 秒座標直覺訓練 (Coordinate Rush)**
   - 隨機出題，30 秒限時極速點擊棋盤對應格（如 e4, c7, g3）。
   - 支援白方 / 黑方視角切換與連擊計分系統。

3. **騎士跳躍幾何運算 (Knight's Path Finder)**
   - 3 大關卡挑戰，計算最少步數吃掉所有星星。
   - 培養對騎士「L 型跳躍」與「黑白格轉換」的幾何空間感知。

4. **技巧指南與訓練心法 (Guide & Strategy)**
   - 經典殘局迷你遊戲（Pawn Wars、Knight & Pawns 等）。
   - 世界冠軍愛用的「啄木鳥訓練法 (The Woodpecker Method)」。
   - 線上精選練習資源推薦。

## 🚀 快速開始

直接用瀏覽器開啟 `index.html` 即可開始練習！
